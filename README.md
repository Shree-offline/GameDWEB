# 🎮 GameDWEB: Guess the Number

GameDWEB is a sleek, web-based "Guess the Number" game built with HTML, CSS, and JavaScript. Players guess a random number between 1 and 100 and receive dynamic, color-coded feedback. It features a modern dark/neon UI, attempt tracking, and responsive design. A fun, interactive project showcasing core front-end web development skills!

## ✨ Features
* **Dynamic Feedback:** Real-time updates telling you if your guess is too high, too low, or correct.
* **Color-Coded UI:** Text colors change based on the game state (e.g., Red for too high, Blue for too low, Green for a win).
* **Attempt Tracking:** Keeps a running tally of how many guesses it took you to win.
* **Input Validation:** Prevents blank submissions and prompts the user for a valid number.
* **Modern Design:** A custom dark mode aesthetic with neon accents and clean CSS flexbox centering.

## 🛠️ Technologies Used
* **HTML5:** For the structure and layout of the game.
* **CSS3:** For styling, layout, and the neon aesthetic.
* **Vanilla JavaScript:** For the core game logic and DOM manipulation.

## 📂 File Structure
This project follows standard front-end web development practices by separating concerns into three files:
* `index.html` - The main web page.
* `style.css` - The stylesheet containing the dark/neon theme.
* `script.js` - The game logic and interactive elements.
